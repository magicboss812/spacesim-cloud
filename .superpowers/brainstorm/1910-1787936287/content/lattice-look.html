Which lattice reads as "deep field" rather than CAD viewport?

All four use the same mechanic you approved: decade levels (1 m, 10 m, 100 m …), each fading in as its on-screen spacing grows and out as it gets too coarse, so zooming continuously hands off between them. Only the look of the lines differs. Every panel is auto-zooming through ~2.5 decades on the same clock, so you can compare the handoff directly.

accent color — this is the single background.accent_color knob, driving the depth glow and the level markers together.

A — Mockup baseline

Exactly the design mockup: uniform faint lines edge to edge, accent cross-ticks at every 3rd vertex of the dominant level. Honest port, but the even weight across the whole frame is the part that reads "drafting sheet".

B — Depth-cued lattice (my pick)

Same lattice, three changes: lines dissolve toward the frame edges so it never looks like a bounded sheet; the three line families carry slightly different weights (1 / .7 / .7) so the field has grain instead of perfect isotropy; and vertices of the dominant level get a soft accent node instead of a hard cross.

C — Node field only

No continuous lines at all — only the lattice vertices, as dots whose size and brightness track the level. Subdivision reads as the field densifying. Furthest from a CAD viewport, and the cheapest to draw; but the grid stops working as a scale reference because you can't trace a cell edge.

D — Range rings

Concentric decade rings plus faint spokes, centred on the current reference body — how range rings actually work on an instrument. Unmistakably orbital. Risk: it competes visually with the orbit lines and the prediction conic, which are also curves, and it needs a reference body to have a centre at all.
